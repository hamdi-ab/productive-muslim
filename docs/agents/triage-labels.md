# Triage labels

The five canonical triage roles, each label string equal to its name. Used by the `triage` skill.

| Role | Label |
|---|---|
| Needs triage | `needs-triage` |
| Needs info | `needs-info` |
| Ready for agent | `ready-for-agent` |
| Ready for human | `ready-for-human` |
| Won't fix | `wontfix` |
