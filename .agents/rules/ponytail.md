## ponytail

Rules:
- Apply the Ponytail Ladder on all coding, refactoring, and architectural tasks:
  1. YAGNI: Question whether speculative logic or abstractions need to exist.
  2. Reuse existing helpers, utilities, and models in the codebase first.
  3. Prefer Dart/Flutter stdlib and framework capabilities.
  4. Use native platform features and already-installed packages over new third-party dependencies.
  5. Shortest clean working diff wins.
- Never compromise on validation, error safety, data integrity, tests, or accessibility.
