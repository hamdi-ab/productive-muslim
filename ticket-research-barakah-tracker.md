# Ticket: Research Barakah tracker data model

## Question

How should the Barakah tracker work in the app? The book describes barakah as "divine attachment to a thing that increases it or makes it beneficial" and lists 18 sources.

Design a data model and interaction pattern for:
1. Logging barakah sources (which of the 18, when, context)
2. Visualizing barakah trends over time
3. Connecting barakah to productivity metrics (tasks completed, habits maintained)
4. Daily/weekly barakah prompts or reminders

Should it be:
- A simple checklist (tick sources each day)?
- A free-form journal with tagging?
- A mood/energy tracker style slider?
- Something else?

Evaluate 2-3 interaction patterns and recommend one.
